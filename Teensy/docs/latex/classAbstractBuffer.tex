\doxysubsection{Detailed Description}
\subsubsection*{template$<$class T$>$\newline
class Abstract\+Buffer$<$ T $>$}

Abstract class to manage the data buffers. 

As this is an abstract class, it cannot be instantiated directly, and is instead used as a base from which the other buffers are derived. Every sampling instance requires at least two data buffers. As one fills up, the next buffer saves data while the filled one awaits to be written to the SD card. Additionally, each data buffer needs to have a short header containing the ID of the data, filled buffer count, and time. This class essentially builds a \mbox{\hyperlink{structBufferHelper}{Buffer\+Helper}} for each buffer passed into it. Note that this class is abstract because it inherits from \mbox{\hyperlink{classBufferBase}{Buffer\+Base}}, which contains a pure virtual function.
