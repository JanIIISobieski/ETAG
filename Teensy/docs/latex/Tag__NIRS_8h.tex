Thus, to use the Artinis \mbox{\hyperlink{classNIRS}{N\+I\+RS}} system, a laptop containing the \mbox{\hyperlink{classNIRS}{N\+I\+RS}} software will have to be used to interface with the system for setting sampling parameters.
