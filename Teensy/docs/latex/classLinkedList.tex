\subsubsection*{template$<$class T$>$\newline
class Linked\+List$<$ T $>$}

Implements the singly linked list. 

This simplifies some code down the line, especially printing out the sampling metadata as \mbox{\hyperlink{classLinkedList}{Linked\+List}} can store pointers to the metadata and then a single print function can iterate through the entire list to print at once.
