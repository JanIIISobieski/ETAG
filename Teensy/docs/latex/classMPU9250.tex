\doxysubsection{Detailed Description}
Class to implement \mbox{\hyperlink{classMPU9250}{M\+P\+U9250}} functionality. 

Based on the libary written by Sparkfun (see \href{https://github.com/sparkfun/SparkFun_MPU-9250_Breakout_Arduino_Library}{\texttt{ here}}), which itself implemented a library by Kris Winer (see \href{https://github.com/kriswiner/MPU9250}{\texttt{ here}}). The interface of these libraries was updated to work with the Abstract Device scheme.
