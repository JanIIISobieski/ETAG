\doxysubsection{Detailed Description}
Structure to hold a timer and a delta time to use for printing variables every so often. 

If variables have to be printed during active running of the program (and would otherwise overwhelm the serial output if printed in \mbox{\hyperlink{main_8cpp_afe461d27b9c48d5921c00d521181f12f}{loop()}}), this structure is used to initialize a timer and a dt for time in between printing the output. See \mbox{\hyperlink{classVarPrinter_a02cee311358bab9abe982eb455036ec1}{Logger\+::print\+\_\+timed\+\_\+variables()}}.
