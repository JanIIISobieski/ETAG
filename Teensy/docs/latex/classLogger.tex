\doxysubsection{Detailed Description}
The main logging class responsible for logging. 

This classes sets up the Linked\+Lists used for storing and then printing the \mbox{\hyperlink{structTimingMetadata}{Timing\+Metadata}} and other updates of structures for logging. Since this class inherits the public interface of \mbox{\hyperlink{classVarPrinter}{Var\+Printer}}, this \mbox{\hyperlink{classLogger}{Logger}} is the one that calls the printing of variables.

\begin{DoxyRefDesc}{Todo}
\item[\mbox{\hyperlink{todo__todo000001}{Todo}}]Would have been more efficient to make \mbox{\hyperlink{classVarPrinter}{Var\+Printer}} have the protected methods become the public methods, and for the public methods of \mbox{\hyperlink{classVarPrinter}{Var\+Printer}} to be the methods contained in \mbox{\hyperlink{classLogger}{Logger}}. Thus, there is a seperate class that prints variables, and then a \mbox{\hyperlink{classLogger}{Logger}} that inherits the print methods and wraps them in Logging level to be used for logging. Not a critical change, but one that would improve the format of the code. \end{DoxyRefDesc}

Adds the Timing\+Data structures to the \mbox{\hyperlink{classLogger}{Logger}}. 

These will be added to a linked list that stores the location of all the Timing\+Data structures. This way, logging the timing metadata simply needs to iterate through the linked list to print them all out. Thus, only the setup code gets a little messier (the \mbox{\hyperlink{structTimingMetadata}{Timing\+Metadata}} is added then to the logger one at a time), but the rest of the code stays clean.
