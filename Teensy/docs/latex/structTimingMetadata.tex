\doxysubsection{Detailed Description}
Structure to store the timing between various functions (filling buffers, main loop timing, etc.) 

This allows for updating the timing information and storing it for later printing. Otherwise, attempting to print the differences in between calls while they happen could result in spending excessive time printing to the output buffer.
