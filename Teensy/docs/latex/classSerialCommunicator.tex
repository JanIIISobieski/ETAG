\doxysubsection{Detailed Description}
This abstract class establishes the interface for serial communication. 

Alias template for the \mbox{\hyperlink{unionbyte__array}{byte\+\_\+array}} union to enable its use as a data type Note that this class cannot inherit from Stream, as Stream does not itself implement the code required for sending data over U\+SB or Serial. Thus, this function instead delegates the write and print functions to the write and print functions that are written in the implementation of Stream class (like usb\+\_\+serial\+\_\+class or Hardware\+Serial).

\mbox{\hyperlink{classTag__USB}{Tag\+\_\+\+U\+SB}} and Tag\+\_\+\+Bluetooth inherit from \mbox{\hyperlink{classTagCommunicator}{Tag\+Communicator}} for their functions. \mbox{\hyperlink{classSerialCommunicator_aa9e65ef3189c3ca6307023e5f6c5bf61}{file\+\_\+send}} is the function that has to be implemented in any dervied class as it is a pure virtual function. This interface thus allows for there to be one communications manager that can query all the available communication devices.
