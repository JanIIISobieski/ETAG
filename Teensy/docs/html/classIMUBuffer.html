This class is responsible for managing the writing, filling, and interrupts that allow the device to sample

void IMUBuffer::reset ( )
virtual

Resets the IMU Buffers and associated indices.

The time and count in the buffers is set to 0, data is zeroed out in the buffers, and the buffer selector, current index, and buffer trigger count is reset to 0.
