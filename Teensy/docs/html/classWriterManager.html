Detailed Description

Class to manage the classes that inherit from Writer.

This class forwards the calls for writing data, writing headers, pre and post sampling routines, to the appropriate Writer.

An index of 0 corresponds to the bluetooth, and index of 1 corresponds to the USB, while an index of 2 corresponds to the SD card (through DiskManager).
