Detailed Description

This abstract class establishes the interface for serial communication.

Alias template for the byte_array union to enable its use as a data type Note that this class cannot inherit from Stream, as Stream does not itself implement the code required for sending data over USB or Serial. Thus, this function instead delegates the write and print functions to the write and print functions that are written in the implementation of Stream class (like usb_serial_class or HardwareSerial).

Tag_USB and Tag_Bluetooth inherit from TagCommunicator for their functions. file_send is the function that has to be implemented in any dervied class as it is a pure virtual function. This interface thus allows for there to be one communications manager that can query all the available communication devices.
