Detailed Description

Class to implement MPU9250 functionality.

Based on the libary written by Sparkfun (see here), which itself implemented a library by Kris Winer (see here). The interface of these libraries was updated to work with the Abstract Device scheme.

Todo:
Rewrite this library in a much cleaner way, eliminating the jank and lack of extensibility, and write proper getter and setter methods for the device status.
Todo:
Finish documentation, but this will likely be finished only after this code is refactored

Initializes the MPU9250.

Returns

Runs a self test, calibrates the device, starts both the MPU9250 (accel/gyro), and then starts the AK8963 (magnetometer), as well as updating the resolutions of all the devices based on the settings.
