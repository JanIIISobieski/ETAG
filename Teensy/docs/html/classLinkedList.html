Detailed Description

template<class T>
class LinkedList< T >

Implements the singly linked list.

This simplifies some code down the line, especially printing out the sampling metadata as LinkedList can store pointers to the metadata and then a single print function can iterate through the entire list to print at once.

Template Parameters
TAny structure or type (e.g. TimingMetadata)
