Detailed Description

This class manages all of the sampling devices.

This class calls each device's init(), while begin(), end() only if the corresponding device_start boolean is true. This allows for only starting select devices. This also results in shorter code for the main function, as only this class's methods must be called to maintain all of the devices. All chips are initalized no matter the state of the bool array.
