Detailed Description

template<class T>
struct BufferHelper< T >

Template structure containing the important descriptors for each buffer.

Template Parameters
TAny valid type (e.g. uint32_t, int16_t, unsigned char, etc.)

Each buffer is of the form:
[ ID | Count | --- Time --- | --------------Data-------------------]
[ 1 byte | 1 Byte | 4 bytes | ---------Remaining Bytes-------------]
