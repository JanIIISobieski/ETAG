enum NIRS_state

Track the NIRS system state.

Note that the NIRS system functions in parallel to the tag. The tag merely emulates button presses. Thus, to use the Artinis NIRS system, a laptop containing the NIRS software will have to be used to interface with the system for setting sampling parameters. The tag controls can merely turn the device on or off, start/stop sampling, and create event timers (that can then be used to align the data with the tag).
